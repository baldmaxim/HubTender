# TenderHUB — машинный доступ к тендерам и сметам

Как подключить любого ИИ-помощника (Cursor, Codex, Claude Code, свой скрипт) к API
TenderHUB по ключу `thk_…` и дать ему **просмотр тендеров и их детальных смет**.

| Файл | Что внутри |
|---|---|
| [README.md](README.md) (этот) | выпуск ключа, проверка связи, сценарий «выбрать тендер → смета», ошибки и лимиты |
| [ENDPOINTS.md](ENDPOINTS.md) | справочник эндпоинтов и полей ответов |
| [ASSISTANTS.md](ASSISTANTS.md) | пошаговое подключение: Cursor, Codex, Claude Code, curl/OpenAPI |
| [AGENT_INSTRUCTIONS.md](AGENT_INSTRUCTIONS.md) | готовый текст инструкции для агента — копировать в `AGENTS.md` / правило Cursor / `CLAUDE.md` |

Живая спецификация OpenAPI 3.1: `GET /api/v1/archive/openapi.yaml`
(исходник — [`backend/internal/handlers/openapi/archive.yaml`](../backend/internal/handlers/openapi/archive.yaml)).
CLI для терминала и агентов: [`scripts/archive-api.mjs`](../scripts/archive-api.mjs).

## Адреса

| Среда | Base URL |
|---|---|
| Прод | `https://tender.su10.ru` |
| Локальный Go BFF | `http://localhost:3005` |

Все пути ниже — относительно base URL. Ответы — JSON в конверте `{"data": …}`,
ошибки — RFC 7807 (`application/problem+json`) с машинным полем `code`.
Крупные ответы сжимаются gzip — клиент должен присылать `Accept-Encoding: gzip`
(curl: `--compressed`).

## Шаг 1. Выпустить ключ

**Настройки → Доступ к API → Ключи → Выпустить ключ** (`/admin/api-access`,
роли `administrator` и `developer`).

| Поле | Для просмотра тендеров и смет |
|---|---|
| Название | «Cursor, Иванов» / «Codex, отдел ПТО» — чтобы было понятно, чей ключ отзывать |
| Права | **«Чтение тендеров и смет»** (`tenders:read`). «Чтение архива смет» — если помощнику нужен ещё и поиск по историческим сметам. Права на запись не выдавать |
| Разрешённые тендеры | пусто — все тендеры; список id — только они (и `/tenders/brief` покажет только их) |
| Действует до | поставить дату; бессрочный ключ на рабочей машине — плохая идея |

Секрет `thk_…` показывается **один раз**; в базе хранится только SHA-256. Потерянный
ключ не восстанавливается — выпускается новый, старый отзывается.

Ключ действует **от имени выпустившего пользователя**: в журнале вызовов и аудите
записи подписаны им.

## Шаг 2. Положить ключ в окружение

Только переменные окружения; ни в аргументы команд, ни в файлы репозитория.

```powershell
# Windows, постоянно (перезапустить терминал/редактор после setx)
setx TENDERHUB_API_KEY "thk_..."
setx TENDERHUB_API_URL "https://tender.su10.ru"
```

```bash
# bash / zsh
echo 'export TENDERHUB_API_KEY="thk_..."' >> ~/.bashrc
echo 'export TENDERHUB_API_URL="https://tender.su10.ru"' >> ~/.bashrc
```

## Шаг 3. Проверить связь

```bash
node scripts/archive-api.mjs tenders --archived=false
# или без Node:
curl -s --compressed "$TENDERHUB_API_URL/api/v1/tenders/brief?is_archived=false" \
     -H "X-API-Key: $TENDERHUB_API_KEY"
```

Ожидаемо — `{"data":[…]}` со списком тендеров (для ключа с ограничением — только
разрешённые). Иначе см. [ошибки](#ошибки-и-лимиты).

## Сценарий: выбрать тендер → посмотреть смету

```bash
# 1. Найти тендер по номеру/названию/заказчику → взять id
node scripts/archive-api.mjs tenders --search="ЖК Север"

# 2. Шапка: заказчик, версия, курсы, итог КП, число позиций и строк
node scripts/archive-api.mjs tender <tender_id>

# 3. Позиции с итогами (себестоимость, КП, наценка, число строк) — вид страницы
#    «Позиции заказчика»; отдельно — позиции с признаком раздела и категорией затрат
node scripts/archive-api.mjs costs <tender_id>
node scripts/archive-api.mjs positions <tender_id> --section=монолит

# 4. Детальная смета: строки работ/материалов с названиями, единицами,
#    количеством, ценой, валютой, категорией затрат и коммерческой стоимостью
node scripts/archive-api.mjs estimate <tender_id>                  # весь тендер
node scripts/archive-api.mjs estimate x --position=<position_id>   # одна позиция
```

То же через HTTP (`-H "X-API-Key: …"` везде):

| Шаг | Запрос |
|---|---|
| выбрать тендер | `GET /api/v1/tenders/brief?search=…&is_archived=false` |
| шапка | `GET /api/v1/tenders/{id}/overview` |
| позиции с итогами и КП | `GET /api/v1/tenders/{id}/positions/with-costs` |
| позиции с разделами | `GET /api/v1/tenders/{id}/positions?limit=200[&cursor=…]` |
| строки сметы (весь тендер) | `GET /api/v1/tenders/{id}/boq-items-full` |
| строки одной позиции | `GET /api/v1/positions/{id}/boq-items-full` |

Крупные тендеры: `with-costs` на 11 тыс. позиций — около 10 МБ, `boq-items-full` ещё
больше. Если помощнику нужна только часть, забирайте по позициям.

## Что ключ может

| Область | Что открывает |
|---|---|
| `tenders:read` | список тендеров, шапка, позиции (с итогами и с разделами), строки сметы, одна строка BOQ. **Только чтение** |
| `archive:read` | поиск по историческим сметам, подбор аналогов, состав исторической позиции |
| `archive:write` | сборка сметы из исторических позиций (`compose`) — запись в тендер |
| `tenders:write` | прямое создание/правка строк BOQ и пересчёт итогов позиции — запись в тендер |

Ограничение по списку тендеров действует для всех областей. Управление ключами и
настройками (`/api/v1/admin/api-access/*`) и остальные эндпоинты портала ключу
недоступны — только JWT пользователя.

## Ошибки и лимиты

| Ответ | Причина | Что делать |
|---|---|---|
| `401` | ключа нет, он отозван, просрочен или скопирован с ошибкой | выпустить новый; причина намеренно не раскрывается, в журнал не пишется |
| `403 API_KEY_SCOPE_DENIED` | ключу не выдана область (в `detail` — какая) | перевыпустить ключ с нужным правом |
| `403 API_KEY_TENDER_DENIED` | тендер вне списка разрешённых | расширить список или взять другой тендер |
| `429` | больше `rate_limit_per_minute` вызовов за минуту (по умолчанию 120 на ключ) | снизить темп; лимит правится в «Настройки → Доступ к API» |
| `503 ENDPOINT_DISABLED` | администратор выключил эндпоинт архива | не обходить |
| `404` | тендер/позиция/строка не найдены | проверить id |
| ответ не JSON (HTML) | ответил прокси, а не приложение | проверить base URL и доступность хоста |

Каждый вызов по ключу попадает в **Настройки → Доступ к API → Журнал вызовов**
(время, ключ, метод, путь, статус, код ошибки, длительность; тела не сохраняются).
Отзыв — кнопка в списке ключей, действует немедленно.

## Безопасность

- Ключ — в переменных окружения, не в `.env` репозитория, не в `mcp.json`, не в правилах.
- Попал в чат, скриншот, git — отозвать сразу и выпустить новый; простоя нет.
- Для помощников выдавайте только чтение; запись (`archive:write`, `tenders:write`) — отдельным ключом с ограничением по тендерам.
