# Бот рассылки замечаний «Проверки данных» TenderHUB

Telegram-бот, который присылает инженерам замечания «Проверки данных» и принимает кнопки/команды (`/stop`).
Программа — тонкий ретранслятор: сама опрашивает Telegram и ходит в API TenderHUB по машинному ключу.
Все тексты, проверки и очередь рассылки живут на сервере; бот ничего не решает, только пересылает.

**Бот работает, только пока включён ПК, на котором он запущен.** Пока ПК выключен, уведомления копятся
в очереди на сервере и уйдут сразу после запуска бота. Формат обмена с сервером — `api/VERIFICATION_BOT.md`
в репозитории.

Нужен только Python: никаких `pip install`.

## Установка на Windows-ПК

1. **Python 3.9+** с [python.org](https://www.python.org/downloads/). В установщике включите галочку **Add Python to PATH**.
2. **Бот в Telegram.** Откройте `@BotFather`:
   - `/newbot` — задайте имя и username (на `bot` заканчивается);
   - `/setcommands` → выберите бота → отправьте `stop - отключить уведомления`;
   - сохраните выданный токен.
3. **Ключ в TenderHUB.** Администрирование → Доступ к API → «Выпустить ключ». Область — «Telegram-бот рассылки замечаний»,
   список тендеров оставьте пустым. Ключ показывается один раз — скопируйте сразу.
4. **Папка бота.** Скопируйте папку `bots/verification-bot` на ПК (например, `C:\bots\verification-bot`).
   Скопируйте `bot.env.example` в `bot.env` и заполните:
   ```
   TELEGRAM_BOT_TOKEN=токен от BotFather
   TENDERHUB_API_KEY=ключ из TenderHUB
   ```
   Остальные настройки необязательны, их описание — в `bot.env.example`. Бот читает настройки **только
   из `bot.env`**: переменные окружения Windows `TENDERHUB_API_URL` / `TENDERHUB_API_KEY`, заданные для
   Cursor или бота перечня, он не трогает. **Не отправляйте `bot.env` никому и не коммитьте** — там секреты.
5. **Запуск.** Двойной щелчок по `run.bat`. В окне и в файле `bot.log` должно появиться:
   ```
   Бот @имя_бота запущен, API TenderHUB: https://gp.su10.ru/api/v1
   Цикл обновлений запущен
   Цикл очереди запущен
   ```
   Остановка — `Ctrl+C` или закрытие окна. Журнал — `bot.log` в папке бота (ротация: 1 МБ × 3 файла).
6. **Автозапуск.** Планировщик заданий → «Создать задачу»:
   - Триггер: «При входе в систему»;
   - Действие: запуск программы `run.bat`, «Рабочая папка» — папка бота;
   - Параметры: «Не запускать новый экземпляр»; в «Условиях» снимите «Запускать только при питании от электросети»
     и «Запускать только при подключении к сети»;
   - Вариант без окна: программа `pythonw`, аргументы `-m verification_bot`, рабочая папка — папка бота
     (тогда смотрите `bot.log`).
7. **Проверка.** В TenderHUB: меню профиля → Telegram → «Привязать» → в Telegram нажмите Start.
   Затем на странице «Проверка данных» отправьте себе находку — сообщение придёт в течение
   `CLAIM_INTERVAL_SECONDS` (по умолчанию 30 с).

## Прокси

Если офисная сеть выходит в интернет через прокси, задайте переменные окружения Windows `HTTPS_PROXY`
(и при необходимости `HTTP_PROXY`), например `http://proxy.office:3128`. Бот подхватывает их сам.
В `bot.env` прокси не задаётся.

## Диагностика

Смотрите `bot.log`.

| Что в логе | Причина и что делать |
|---|---|
| `Неверный TELEGRAM_BOT_TOKEN` | Токен в `bot.env` неверный или отозван. Возьмите новый у @BotFather (`/token`). Бот завершается с кодом 2. |
| `ключ TenderHUB отклонён (HTTP 401/403)` | Неверный, отозванный ключ или нет области «Telegram-бот рассылки замечаний». Выпустите ключ заново. Бот повторяет попытки сам. |
| `TenderHUB ответил не API, а страницей (HTML)` | Неверный `TENDERHUB_API_URL`: нужен `https://gp.su10.ru/api/v1` (`/api/v1` бот допишет сам) либо перед сервером стоит чужая страница/прокси. |
| `нет API бота (HTTP 404/405)` | По адресу из `TENDERHUB_API_URL` не TenderHUB. `tender.su10.ru` с 14.10 указывает на другой сервер — нужен `https://gp.su10.ru`. |
| `HTTP 301: адрес перенаправляет` | В `TENDERHUB_API_URL` http вместо https или устаревший домен. |
| `Бот уже запущен на другом компьютере (или у бота задан webhook)` (409 Conflict) | Бот запущен ещё раз на другом ПК или во втором окне; или у бота установлен webhook. Оставьте один экземпляр. |
| `Ошибка опроса Telegram` / `TenderHUB недоступен` | Нет сети или заблокирован доступ. Бот повторяет попытки с паузой до 60 с. Проверьте прокси (`HTTPS_PROXY`). |
| `Не заданы обязательные настройки: …` | Не заполнен `bot.env`; в сообщении перечислены имена ключей. |
| В TenderHUB «бот не в сети» | Сервер видит бота, только если от него был запрос очереди за последние 90 с. ПК выключен, бот не запущен или завис — смотрите `bot.log`, перезапустите `run.bat`. |

Если сообщение не доходит до одного человека, а остальным приходит — он заблокировал бота или не нажимал Start
(в логе — `Forbidden: bot was blocked by the user`); решение принимает сервер.
