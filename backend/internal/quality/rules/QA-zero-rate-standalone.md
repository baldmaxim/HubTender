## Суть

Цена за единицу = 0, и строка **не выглядит носителем** привязанных материалов.

Правило **Q** на «Большой Татарской» дало 430 находок — все работы без цены. Часть из
них законна: работа с qty≈1 держит дочерние материалы и сама в деньги не входит.
Остальное — незаполненная расценка.

Заменяет правило **Q** (выключено). Не считаются ошибкой:

- **работа-носитель** — у её привязанных материалов есть деньги, стоимость работы сидит в
  них. Количество работы не важно: на «Большой Татарской» все 430 находок Q — носители с
  объёмом, а не «1 шт»;
- **строка позиции с обоснованием** в «Примечании ГП» — позиция не расценена сознательно
  (тот же смысл, что у правила V).

Остаются работы и материалы без цены там, где стоимость больше нигде не учтена.

## SQL

```sql
SELECT
  b.tender_id,
  cp.position_number,
  cp.item_no,
  b.id AS entity_id,
  md5(concat_ws('|', trim_scale(COALESCE(b.unit_rate, 0)),
                trim_scale(COALESCE(b.quantity, 0)), b.boq_item_type::text)) AS fingerprint,
  concat_ws(' ',
    CASE WHEN b.boq_item_type::text LIKE '%раб%' THEN 'Работа' ELSE 'Материал' END,
    'без цены; количество', round(COALESCE(b.quantity, 0), 4)::text,
    'ед., итог', round(COALESCE(b.total_amount, 0), 2)::text, '₽') AS detail,
  NULL::numeric AS money_delta
FROM public.boq_items b
JOIN public.client_positions cp ON cp.id = b.client_position_id
WHERE b.tender_id = $1
  AND COALESCE(b.unit_rate, 0) = 0
  -- Позиция с обоснованием в «Примечании ГП» не расценена сознательно — тот же
  -- смысл, что у правила V («Садовническая 69»: 708 из 783 таких материалов).
  AND COALESCE(btrim(cp.manual_note), '') = ''
  -- Работа-носитель: её стоимость сидит в привязанных материалах. Количество
  -- работы не важно — на «Большой Татарской» все 430 таких работ с объёмом ≠ 1.
  AND NOT (
    b.boq_item_type::text LIKE '%раб%'
    AND EXISTS (
      SELECT 1 FROM public.boq_items c
      WHERE c.parent_work_item_id = b.id
        AND COALESCE(c.total_amount, 0) > 0
    )
  )
ORDER BY cp.position_number
```

## Подтверждено

- TP: «Садовническая 69», поз. 8.2 — «Смесь сухая Litokol CR 55FT Light», 6 378.87 кг
  без цены в позиции на 366 млн ₽; поз. 13.3 — «Краны, подъёмники», 393 ед. без цены.
- TP-кандидаты: «ЖК События 6.2» v1–v2 и «ЖК Остров 14» — «Разработка КМ/КМД СПК» без
  цены в расценённых позициях (включено в цену СПК или забыто — решает инженер).
- FP (исключены): «Большая Татарская» v2 — 430 работ-носителей; «Садовническая 69» —
  708 материалов в позициях с обоснованием в «Примечании ГП»; «Река 4», примыкание
  кладки (работа-носитель, qty = 1).
